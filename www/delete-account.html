계정 및 데이터 삭제 요청

Monster Arena (몬스터 아레나) · 개발자: sea9401 · 최종 업데이트: 2026-06-03

본 안내는 Monster Arena 앱의 계정과 관련 데이터 삭제를 요청하는 방법을 설명합니다.

삭제 요청 방법 (단계)

  1. sea9401@gmail.com 으로 이메일을 보냅니다.
  2. 제목에 계정 삭제 요청 이라고 적습니다.
  3. 본문에 계정을 식별할 수 있도록 아이디(username) 또는 친구 코드(6자리)를 적습니다.
  4. 요청을 받으면 본인 확인 후 7일 이내에 데이터를 삭제하고, 완료를 이메일로 회신합니다.

계정을 만들지 않고 플레이한 경우, 데이터는 기기에만 저장되며 앱 삭제 또는 로그아웃으로 제거됩니다.

삭제되는 데이터

  • 계정 정보 — 아이디, 비밀번호 해시
  • 게임 진행 데이터 — 펫 스탯·레벨·코인·아이템·칭호·업적·전투 기록·레이팅
  • 소셜 데이터 — 친구 코드 및 친구 관계, 주고받은 선물·메시지
  • 푸시 구독 정보 — 알림을 켰던 경우의 푸시 토큰
  • 기기 식별용 무작위 ID — 서버에 연결된 세이브 식별자

보관되는 데이터 및 보관 기간

  • 삭제 요청 시 위 데이터는 운영 서버에서 영구 삭제되며, 이후 별도로 보관하지 않습니다.
  • 운영 서버의 자동 백업본에 일시적으로 남은 사본은 최대 8일 이내 순환 삭제로 완전히 제거됩니다.
  • 법령상 보존이 요구되는 경우를 제외하고는 어떠한 데이터도 추가 보관하지 않습니다.

Account & Data Deletion Request

Monster Arena · Developer: sea9401 · Last updated: 2026-06-03

This page explains how to request deletion of your Monster Arena account and associated data.

How to Request Deletion (Steps)

  1. Send an email to sea9401@gmail.com.
  2. Use the subject line Account Deletion Request.
  3. Include your username or 6-character friend code so we can locate your account.
  4. After verifying your request, we delete your data within 7 days and confirm by email.

If you played without creating an account, your data is stored only on your device and is removed by uninstalling the app or logging out.

Data That Is Deleted

  • Account info — username, hashed password
  • Game progress — pet stats, level, coins, items, titles, achievements, battle records, rating
  • Social data — friend code & friendships, gifts/messages sent and received
  • Push subscription — push token, if notifications were enabled
  • Random device ID — the save identifier linked to the server

Data Retained & Retention Period

  • Upon request, the above data is permanently deleted from our production servers and is not retained afterward.
  • Residual copies in automated backups are fully removed by backup rotation within 8 days.
  • No data is retained beyond this, except where retention is required by law.
